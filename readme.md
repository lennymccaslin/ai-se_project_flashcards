# Flashcard App

This is my first project created through TripleTen's AI-Assisted Software Engineering program. Included within the scope of the project is a list of flashcard decks, each with multiple flippable cards that can be viewed via carousel.

## Features

- The app is accessible on desktop and mobile
- The user can create, delete, edit and browse multiple flashcard decks
- Each deck is viewable individually via a carousel that allows the user to view and flip each individual card in the deck
- Each card has a question side and an answer side

## Technologies used

- HTML
- CSS
- JavaScript
